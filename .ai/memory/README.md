# Repository Memory

These files are committed team knowledge used by the repository workflow agents.

- `general.md` contains stable repository facts.
- `patterns.md` contains implementation patterns worth reusing.
- `decisions.md` contains approved architectural and product decisions.
- `testing.md` contains validation practices and lessons.
- `styling.md` contains the shared visual language for consistent pages.

Story-specific working files belong under `.ai/sessions/` and are not committed.
Memory updates are made during an approved retrospective and should remain concise, factual, and reusable.
